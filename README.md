IconMaker - Quick Start
=======================

FILES
-----
Keep these two files in the same folder:
  - convert_icons.py
  - Run_IconMaker.bat

USAGE
-----
1. Double-click Run_IconMaker.bat.
2. Type a menu number and press Enter.
3. Choose 5 to install/repair Pillow if needed.
4. Put images in the inputs folder.
5. Choose 1 to convert them.
6. Converted .ico files are saved in outputs.
7. Choose 2, 3, or 4 to open inputs, outputs, or crashlog.

The script creates inputs, outputs, and crashlog automatically.
Requires Python 3 and the Pillow library.
